# Figure 23 — Case Study II: Latent-Space Structure and Interpolation

Case Study figure generated by an actual VAE trained on the public scikit-learn digits dataset.

Protocol: fixed stratified 80/20 split, seed 23023, 85 epochs, 12-dimensional latent space. The upper panel is an actual decoder interpolation between posterior means of authentic held-out class-1 and class-8 observations. The lower panel measures decoded-image RMSE and latent distance at each interpolation step. A logistic-regression probe trained only on training-set latent means provides an auxiliary quantitative check of class information retained in the representation.

This is a compact reproducible case study, not a state-of-the-art representation-learning benchmark.

Run `python src/figure23.py`. Outputs include PNG, SVG, interpolation-path data, step metrics, training log, and summary metrics.
