# Figure 16 provenance

Source: Mohammad Jalali, Cheuk Ting Li, and Farzan Farnia,
"An Information-Theoretic Evaluation of Generative Models in Learning Multi-modal Distributions,"
Advances in Neural Information Processing Systems 36 (NeurIPS 2023), Table 1.

Dataset: CIFAR-10.

The CSV stores only the published values used in the figure: FID, Precision, Recall, and Coverage.
No benchmark values are invented or inferred.

The heatmap color is a visualization transform computed independently within each metric column.
For FID, the transform is inverted because lower FID is better. Numeric cell annotations are the raw
published values and are not transformed.
