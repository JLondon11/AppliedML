# Applied Machine Learning — Canonical Book Repository

The `book/` tree is the canonical publication organization of the complete manuscript.

Each chapter has the same release schema:
- `manuscript/`: final LaTeX and proof PDF
- `figures/`: section-organized final figures and provenance manifest
- `code/`: complete code/reproducibility manifest
- `instructor/`: complete worked solutions and grading guidance
- `qa/`: manuscript, figure, code, and reproducibility audits

Historical production-pass folders remain outside `book/` for provenance. Springer Pass 20 is the current manuscript baseline.

A chapter is certified only when its manuscript, figures, code, solutions, and QA artifacts are all present and reproducibility status is explicit.
