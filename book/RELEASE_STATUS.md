# Canonical Book Release Status

This file is intentionally strict.

The canonical GitHub book release is not certified until every one of the 12 chapter directories contains:
- final chapter.tex and chapter.pdf;
- final figure manifest and section-organized figure assets;
- complete code inventory/audit/reproducibility files;
- complete instructor solutions in LaTeX and PDF;
- chapter QA.

The GitHub Actions workflow "Book release completeness" is the authoritative structural gate.
