# Figure 3 — Byte-Pair Encoding (BPE)

**Chapter:** Natural Language Processing, Part II  
**Section:** Tokenization and Representation  
**Figure:** 3

This directory contains the reproducible scientific-rendering source and the numerical outputs for the BPE figure. The corpus is fixed in `figure_03_bpe.py`; merge frequencies, symbol-count reductions, and tokenization lengths are computed by the code.

## Files

- `figure_03_bpe.py` — complete figure-generation code.
- `figure_03_bpe_merges.csv` — merge-by-merge numerical provenance.
- `figure_03_bpe_tokenization.csv` — token sequence lengths at selected merge checkpoints.
- `figure_03_bpe.png` and `figure_03_bpe.svg` — generated by running the script.

## Reproduce

```bash
python figure_03_bpe.py
```

Requires Python 3 and Matplotlib. The script writes both publication raster and vector outputs plus the CSV provenance tables into this directory.
