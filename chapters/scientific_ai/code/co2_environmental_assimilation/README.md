# Chapter 11 — Real-observation environmental state assimilation

**Scope:** a separately titled Level A demonstration of one-week-ahead station-level environmental measurement assimilation. It is **not** a multi-physics or operational scientific digital twin and does not certify the broader *Application: Scientific Digital Twins*.

## Authentic source
- Historical weekly Mauna Loa atmospheric CO2 concentrations (ppmv), Keeling and Whorf (2004), public domain, packaged with `statsmodels.datasets.co2`.
- Source documentation: https://www.statsmodels.org/stable/datasets/generated/co2.html
- 2,284 weekly timestamps, 2,225 observed, 59 missing.
- Chronological sample counts of *observed* values: training 1,807 (1958–1993); validation 209 (1994–1997); test 209 (1998–2001). Missing observations are not filled with invented measurements.

## Execution
```bash
python -m pip install numpy pandas statsmodels matplotlib
python chapters/scientific_ai/code/co2_environmental_assimilation/run_co2_assimilation.py
```
The script uses a linear trend and two annual Fourier harmonics learned on the training period, selects a random-walk residual process variance by validation RMSE, and performs prospective one-step prediction before consuming each current observation. Comparators are the frozen training-fit trend model and an observed year-lag forecast. Fixed model selection and ordered data remove stochastic seed dependence.

## Measured output
The script writes `results/metrics.csv`, `results/predictions.csv`, `results/manifest.json`, and figures `figures/CO2_assimilation.png/.svg` and `figures/CO2_validation.png/.svg`. Check numeric output against the recorded values in `recorded_test_metrics.csv`: all numbers are ppm, on 209 genuinely observed holdout weeks. The full original Pass 11 evaluation also records signed bias, interval coverage and process variance sensitivity.

- Frozen historical trend: RMSE 4.58452, MAE 4.55561.
- Year-lag observed baseline: RMSE 2.00994, MAE 1.78612.
- Sequential Kalman residual assimilation: RMSE 0.39408, MAE 0.29613.
- Selected process variance q=0.5 ppm^2/week.
- Nominal 90% interval coverage: 100%, mean width 4.9405 ppm; the intervals are too conservative and should **not** be called calibrated.
