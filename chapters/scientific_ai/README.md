# Scientific AI figure production package

This directory contains the current production figure assets for the Scientific AI chapter, together with provenance data and generation code used in the September 2026 production pass.

## Production rules

- Frozen-inventory-first production.
- No infographic grammar for scientific figures.
- Quantitative Application and Case Study figures must use real data and/or executable experiments.
- No invented numerical results.
- Panel letters, when prescribed, appear below their panels and every panel is described in the unified caption.
- SVG is the canonical vector delivery format for code-rendered figures; Figure 1 is retained as the current raster rendering from the image-generation pass.
