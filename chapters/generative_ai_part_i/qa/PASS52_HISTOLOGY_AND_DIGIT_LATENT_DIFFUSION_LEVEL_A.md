## CH6-D12: original scanned digits — class-conditioned latent diffusion

**Precisely certified scientific question:** Can a native digit-label-conditioned latent diffusion generator, trained on original scanned 8×8 handwritten digits, produce samples that a classifier trained *only on genuine digit observations* recognizes as matching the requested labels?

- Original authentic scikit-learn digit scan dataset **N = 1,797**. Actual **1,257 training / 270 validation / 270 genuine held-out test**, no train/test overlap; original source dataset SHA256 and checkpoint/indices verified from execution manifest.
- Actual **16-dimensional VAE trained for 25 epochs**, two trained **48-step latent denoisers** (conditional and unconditional, 35 epochs each), sampling **1,000 output images per model**. Generated outputs are mathematical model images, not new photographs.
- Original training-image-only classifier scored **95.185% accuracy on genuine held-out scanned digit tests** (the benchmark classifier is an indirect generator judge, not a visual-quality authority).
- Of **1,000** actual conditional generated images, **778** agree with the requested digit label; of **1,000** unconditional controls with assigned reference prompts, **94** agree. The 22 original per-arm/per-digit count rows in `code/section_6_20_1_latent_diffusion_digits/figure_6_44_class_counts_pass27.csv` were read directly from GitHub; they sum exactly to **778/1,000** and **94/1,000**. All ten per-digit classes have **100** observed generated outputs per arm.
- Earlier Pass23/47 model evidence established authentic source hashes, actual trained checkpoints, saved **2,000** classifier probability records, original output panels and measured figure generation. R2 uses actual true split and train-only classifier. R5 compares actual conditional and unconditional model arms at the stated fixed training configuration. R6 is genuine generated-sample classifier agreement with sample counts and severe limitations, not an externally validated image realism metric. R7 original low-resolution *digit class* domain only. R8 original output figures and classwise original-data figure source exist; source `figure_6_44_publication.py` generates a substantive observed-per-class error point/interval graphic rather than a simple bar. - **R1–R10 PASS at Level A only**, conditional on its explicit low-resolution digit-label classifier-agreement scope.
