\paragraph{Dataset and experimental protocol.}
The scikit-learn Digits dataset contains 1,797 labeled grayscale handwritten-digit images, each with spatial resolution $8\times 8$ pixels. A stratified random partition (seed 20261105) assigned 1,078 images to training, 359 to validation, and 360 to held-out testing. The three subsets were disjoint. A convolutional neural network containing two $3\times3$ convolutional layers and 28,930 trainable parameters was optimized using Adam with a learning rate of 0.002. The best model checkpoint was selected using validation cross-entropy; testing data did not determine training duration or model selection.

\paragraph{Measured results and interpretation.}
Training continued for 51 epochs and the minimum validation loss occurred at epoch 43, as shown in Figure~\ref{fig:ch2_digits_threeway_loss}. After restoring that checkpoint, the model classified 351 of 360 previously held-out test images correctly, giving 97.50\% test accuracy, macro-averaged $F_1$ of 0.9752, and a test cross-entropy of 0.0993. Figure~\ref{fig:ch2_digits_threeway_cm} presents the test-set confusion matrix; Figure~\ref{fig:ch2_digits_threeway_examples} compares actual predictions with ground-truth test labels; and Figure~\ref{fig:ch2_digits_threeway_maps} shows activation maps from the first convolutional layer for a held-out sample. These results represent one model and one fixed partition of the scikit-learn Digits dataset and must not be interpreted as MNIST benchmark performance or as a multi-seed estimate of generalization.
