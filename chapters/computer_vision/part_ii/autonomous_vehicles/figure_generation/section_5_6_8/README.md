# Chapter 5 Section 5.6.8: controlled calibration-sensitivity experiment

Run `python generate_calibration_sensitivity.py` with NumPy and Matplotlib installed.

**Scope:** deterministic generated optical-frame 3D point positions, not KITTI, nuScenes, Waymo, Argoverse 2, trained-model inference or vehicle deployment. Seed: 568. There are 360 moving targets at 12–50 m depth and lateral speeds from -3 to +3 m/s. Focal lengths are both 680 pixels; principal point (640,360). The script reports pixel RMS errors for timing offsets of 0, 50, 100, 200 ms and yaw calibration offsets of 0, 0.1, 0.25, 0.5 degrees, and emits PDF/PNG/SVG.

The formal quantitative results are generated by the Python script itself, which is authoritative. The adjacent manuscript figure must not be interpreted as a real-data detector, tracking, autonomous-driving cross-dataset, or deployment performance result.

**Experiment limitation:** The baseline is exact pinhole projection without noise; no sensor synchronization estimates or model checkpoints are used. Compare only with its own zero-perturbation control.
