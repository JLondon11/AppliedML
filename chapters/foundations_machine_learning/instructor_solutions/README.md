## Code policy

All executable code referenced by the instructor solutions is stored under `code/` in this directory. No solution depends on an uncommitted notebook or external local script. Heavy benchmark scripts download public datasets/environments at runtime when necessary; deterministic seeds, configuration logging, and output paths are part of each script.

Run `python code/verify_solutions_code.py` to syntax-check the solution scripts without downloading datasets.
