## Current migration rule

## Empirical case-study requirement
Every case study/application must include:
1. several introductory/background paragraphs establishing motivation;
2. Problem, Objective, Model, Metrics/Benchmark, Results, and comparative analysis;
3. a named real dataset with source/provenance and an explicit split/evaluation protocol;
4. complete executable code committed under the chapter code tree;
5. numerical outputs and at least one output/results figure generated by that code;
6. manuscript discussion that explicitly references and interprets every generated figure/table.

Synthetic, simulated, illustrative, or manually fabricated numerical results do not satisfy this empirical case-study requirement.
